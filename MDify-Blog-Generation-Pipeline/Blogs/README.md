# Blogs

One working folder per article, named after its slug:

```
Blogs/{slug}/
  research.md   keyword and SERP notes: queries, country, language, date, gaps
  outline.md    title, TL;DR, sections, FAQs, frontmatter draft
  sources.md    every source behind a claim, with its date
  tests/        saved evidence for any first-hand test or benchmark you cite
```

The finished article does not live here. It goes to
`frontend/content/blog/{slug}.md` (see `../04-OUTPUT-FORMAT.md`).
